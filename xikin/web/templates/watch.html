How it works

  1. 1 Save a query (optionally with an interval).
  2. 2 The scheduler runs due jobs sequentially, one at a time.
  3. 3 Each run compares its result URLs with the previous run.
  4. 4 New URLs trigger a webhook (when configured) and appear here.

Runs use the normal pipeline, evidence chain and safety filters. Watch jobs never scrape more than the mode defaults; adjust depth by running a full investigation.
